Как опубликовать:
1. Создайте публичный репозиторий на GitHub и загрузите в него ВСЕ файлы из этой папки (index.html должен быть в корне).
2. Settings > Pages > Branch: main, / (root). Custom domain: desolutions.kz. Включите Enforce HTTPS.
3. В DNS у регистратора: 4 A-записи @ -> 185.199.108.153, .109.153, .110.153, .111.153 и CNAME www -> ваш-логин.github.io.
4. Замените все метки [ЗАМЕНИТЬ: ...] (поиск по файлам), ссылку Telegram и YOUR_FORM_ID в форме.
5. Добавьте сайт в Google Search Console и Яндекс Вебмастер, отправьте sitemap.xml.
